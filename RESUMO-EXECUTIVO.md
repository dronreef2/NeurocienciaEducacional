# Resumo Executivo — Programa de Pesquisa em Neurociência Educacional

> **5 projetos, 5 anos (2026-2030), 1 orientadora, 1 repositório**

---

## 🎯 Visão Geral

Este programa de pesquisa investiga como **Inteligências Artificiais generativas**
(IA/GenAI) impactam o desenvolvimento cognitivo, emocional e acadêmico de crianças
do 2º ao 5º ano do Ensino Fundamental, com foco em **funções executivas** (FE),
**leitura** e **engajamento escolar**.

A abordagem combina métodos **qualitativos**, **quantitativos** e **neurocientíficos**
para gerar evidências robustas e aplicáveis ao contexto educacional brasileiro.

## 📚 Os 5 Projetos

### **P01** — IA Generativa e Cognição de Teoria da Mente (Qualitativo)

| | |
|---|---|
| **Tipo** | Qualitativo exploratório (Braun & Clarke, 2022) |
| **N** | 12-15 crianças (saturação) |
| **Duração** | 18 meses |
| **Instrumentos** | Diários de bordo (2 semanas), entrevistas, think-aloud, TCLE/TALE |
| **Análise** | Análise Temática Reflexiva (ATR) + análise estatística (5 testes) + rede de códigos |
| **Resultados esperados** | MToM, preferências, padrões emergentes |
| **Revista-alvo** | Computers & Education (A1, IF ~12) |
| **Status** | Piloto concluído (n=3) ✅, manuscrito v1 escrito ✅ |
| **Pré-registro** | OSF ✅ |

**Pergunta:** Que MToM crianças de 7-11 anos constroem em relação a GenAIs?

**5 temas emergentes** (piloto):
1. **Antropomorfização Condicional** — atribuição de agência calibrada
2. **Detecção Precoce de Erro** — literacia crítica emergente
3. **Confiança Calibrada** — confiança modulada por contexto
4. **Comparação Sistemática** — IA como mais uma fonte (não autoridade)
5. **Preferência Contextual** — multimodalidade (texto/voz/imagem)

### **P02** — Gamificação e Funções Executivas (ECR)

| | |
|---|---|
| **Tipo** | Experimento Controlado Randomizado (ECR) 2×4 |
| **N** | 200 (4 grupos × 50) |
| **Duração** | 14 meses |
| **Grupos** | Controle, Pontos, Narrativa, Pontos+Narrativa |
| **Instrumentos** | Stroop, TMT, Digit Span, gamificação (app própria) |
| **Análise** | ANCOVA + modelos mistos + simulação |
| **Revista-alvo** | Computers in Human Behavior (A1, IF ~9) |
| **Status** | Protocolo completo ✅, simulação ✅ |
| **Pré-registro** | OSF ✅ |

**Pergunta:** A gamificação (pontos + narrativa) melhora FE em crianças?

**Hipóteses:**
- H1: Pontos melhoram atenção sustentada
- H2: Narrativa melhora memória de trabalho
- H3: Combinação (P×N) tem efeito aditivo
- H4: Efeitos mediados por engajamento

### **P03** — IA Generativa e Leitura (EEG)

| | |
|---|---|
| **Tipo** | Quase-experimental com EEG (32 canais) |
| **N** | 60 crianças (30 papel + 30 tela) |
| **Duração** | 18 meses |
| **Método** | ERP (P1, N1, P300, N400) |
| **Instrumentos** | EEG 32-ch, tarefas de leitura, eye-tracker |
| **Análise** | ERP + ANOVA + cluster-based permutation |
| **Revista-alvo** | NeuroImage (A1, IF ~6) |
| **Status** | Protocolo completo ✅, simulação ✅ |
| **Pré-registro** | OSF ✅ |

**Pergunta:** Como a leitura em tela vs papel modula o processamento neural?

**Componentes esperados:**
- **N170** (processamento visual de palavras)
- **P300** (atenção)
- **N400** (integração semântica)
- **P600** (reparsing sintático)

### **P04** — IA Generativa e FE (SEM Transversal)

| | |
|---|---|
| **Tipo** | Transversal correlacional com SEM |
| **N** | 300-500 crianças |
| **Duração** | 15 meses |
| **Modelo** | X (IA) → M (Engajamento) → Y (FE), W (Letramento digital) modera |
| **Instrumentos** | BRIEF-2, EvsD, Stroop, TMT, Digit Span, Questionário uso |
| **Análise** | CFA + SEM + Mediação + Moderação |
| **Revista-alvo** | Computers in Human Behavior (A1, IF ~9) |
| **Status** | Protocolo completo ✅ |
| **Pré-registro** | OSF ✅ |

**Pergunta:** Como o uso de IA afeta FE, mediado por engajamento e moderado por letramento digital dos pais?

**Hipóteses:**
- H1: X → M (efeito direto, β ≈ 0.30)
- H2: M → Y (efeito direto, β ≈ 0.40)
- H3: Indireto significativo
- H4: W × X significativo (moderação)

### **P05** — Coorte Longitudinal de FE (LGCM)

| | |
|---|---|
| **Tipo** | Coorte longitudinal (5 ondas) |
| **N** | 200 crianças (5 séries × 40) |
| **Duração** | 30 meses |
| **Ondas** | 2º → 3º → 4º → 5º → 6º ano |
| **Instrumentos** | IRT Rasch, mixed models, redes longitudinais |
| **Análise** | LGCM + IRT + Análise de Sobrevivência + Item Analysis |
| **Revista-alvo** | Child Development (A1, IF ~6) |
| **Status** | Protocolo completo ✅, simulação ✅ |
| **Pré-registro** | OSF ✅ |

**Pergunta:** Como as FE se desenvolvem ao longo do Ensino Fundamental?

**Análises planejadas:**
- **LGCM** (Latent Growth Curve Models)
- **IRT** (Item Response Theory - Rasch 1PL)
- **Análise de Sobrevivência** (Kaplan-Meier + Cox)
- **Análise Clássica de Itens** (CTT)
- **Mixed Models** longitudinais

## 🔬 Métodos e Técnicas

### Quantitativos
- **Estatística descritiva** e inferencial (t-test, ANOVA, qui-quadrado, correlação)
- **Modelos mistos** (LMM) para dados longitudinais
- **Modelagem de Equações Estruturais** (SEM) para mediação/moderação
- **IRT** (Item Response Theory) para medidas psicométricas
- **Latent Growth Curve Models** (LGCM) para trajetórias de desenvolvimento
- **Análise de Sobrevivência** (Kaplan-Meier, Cox)
- **Análise Bayesiana** (priors informativos, MCMC)
- **Análise de Poder** (simulação Monte Carlo)

### Qualitativos
- **Análise Temática Reflexiva** (Braun & Clarke, 2022)
- **Análise de Conteúdo** (Bardin)
- **Análise de Discurso** (Fairclough)
- **Análise de Rede** de códigos (NetworkX)
- **Análise de Sentimento** (PT-BR lexicon)

### Neurocientíficos
- **EEG** (32 canais)
- **ERP** (Event-Related Potentials)
- **Pré-processamento** (filtros, ICA, artefatos)
- **Análise tempo-frequência** (wavelet, FFT)
- **Análise de fontes** (sLORETA)
