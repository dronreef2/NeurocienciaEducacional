🔧 Alternativa: API Automatizada

Se preferir automatizar o upload via API, o OSF suporta POST direto:

curl -X POST https://api.osf.io/v2/registrations/ \ -H "Authorization: Bearer <OSF_TOKEN>" \ -H "Content-Type: application/json" \ -d @docs/osf-json/P01-osf.json

Para gerar token: osf.io/settings/tokens

  • ✓ Compartilhar no Twitter/X com hashtag #OpenScience
