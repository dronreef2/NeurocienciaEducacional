# ✅ Checklist Operacional — Reunião com Ângela

> **Sequência completa** do zero até o follow-up pós-reunião.
> **Marcar** cada item conforme avança. **Levar este checklist** no celular no dia.

---

## FASE 0 — PREPARAÇÃO (1 semana antes)

### Materiais a preparar
- [ ] **Briefing pack** (2 páginas) — imprimir 3 cópias
  - Arquivo: `docs/atas/2026-XX-XX-reuniao-angela-briefing.md`
- [ ] **Termo de orientação** (autorização) — imprimir 2 vias
  - Arquivo: `docs/atas/2026-XX-XX-reuniao-angela-autorizacao.md`
- [ ] **Manuscrito P01 v1** — imprimir 1 página de destaque
  - Arquivo: `01-projeto-qualitativo-criancas-ia/manuscritos/P01_manuscrito_v1.md`
- [ ] **Lista de leituras-chave** (8 papers seminais) — imprimir 1 página
  - Arquivo: `00-fundamentos/bibliografia-seminais.md`

### Logística
- [ ] **Data/hora** confirmada (mútua, 3 opções enviadas, ela escolheu)
- [ ] **Local** confirmado (Natal / Caicó / Google Meet)
- [ ] **Convite Google Calendar** enviado (com link do Meet se remoto)
- [ ] **Material impresso** (não confiar só no digital)
- [ ] **Carregador de celular** (mostrar repo no Meet se remoto)

### Pitch
- [ ] **Roteiro de 5min** memorizado (não ler)
  - Arquivo: `docs/atas/2026-XX-XX-reuniao-angela-agenda.md` (seção "Roteiro de Pitch")
- [ ] **3 perguntas antecipadas** decoradas (com respostas)
  - "Por que 5 projetos?"
  - "Já tem financiamento?"
  - "Como vai conciliar com o trabalho?"
- [ ] **3 dúvidas-chave** preparadas (não improvisar)

---

## FASE 1 — DIA DA REUNIÃO (3 horas antes)

### Checklist físico
- [ ] **Briefing pack** impresso (3 cópias)
- [ ] **Termo de orientação** impresso (2 vias)
- [ ] **Manuscrito P01** (1 página)
- [ ] **Lista de leituras** (1 página)
- [ ] **Caderno físico** + caneta (orientadoras tradicionais valorizam)
- [ ] **Documento de identidade** (para assinar termo)
- [ ] **Cartão de visita** (se tiver — opcional)

### Checklist técnico
- [ ] **Notebook carregado** (para mostrar repo, se necessário)
- [ ] **Internet testada** (se remoto)
- [ ] **Repositório aberto** no navegador (https://github.com/dronreef2/NeurocienciaEducacional)
- [ ] **Dashboard aberto** (https://<app>.streamlit.app)
- [ ] **Câmera e microfone** testados (se remoto)

### Estado mental
- [ ] **Dormiu 7+ horas** na noite anterior
- [ ] **Tomou café** (orientação não é hora de hipoglicemia)
- [ ] **Revisou pitch** 30 min antes
- [ ] **Respirou fundo** 5 minutos antes (calmness is power)

---

## FASE 2 — DURANTE A REUNIÃO (15-30 min)

### Abertura (2-3 min)
- [ ] **Agradecer** pelo tempo dela
- [ ] **Contextualizar** o porquê da reunião
- [ ] **Mostrar entusiasmo controlado** (não excessivo)

### Pitch central (5 min)
- [ ] **Programa em 1 frase**
- [ ] **5 projetos em tabela** (mostrar briefing p.1)
- [ ] **Cronograma real** (60 meses)
- [ ] **O que está pronto** (90% do programa)

### Decisões (5-10 min)
- [ ] **Bloco A** (orientação) — apresentar termo
- [ ] **Bloco B** (submissões) — pedir autorização
- [ ] **Bloco C** (rede) — pedir escola + contato Pereira

### Negociação (5-10 min)
- [ ] **Ouvir mais do que falar** (70/30)
- [ ] **Anotar** as preocupações dela (caderno físico)
- [ ] **Flexibilizar** o que for possível
- [ ] **Marcar** pontos não-acordados para "próxima reunião"

### Fechamento (2-3 min)
- [ ] **Resumir** decisões em voz alta
- [ ] **Assinar termo** (se ok) ou combinar prazo
- [ ] **Agendar próxima reunião** (1ª terça do próximo mês)
- [ ] **Trocar WhatsApp/Slack** (se ainda não tiver)
- [ ] **Entregar materiais** (briefing + termo assinado)
- [ ] **Agradecer** pessoalmente

---

## FASE 3 — PÓS-REUNIÃO (24-48h)

### Imediato (até 2h depois)
- [ ] **Anotar tudo** no caderno antes de esquecer (memória fresca)
- [ ] **Escrever ata** em `docs/atas/AAAA-MM-DD-reuniao-angela-ata.md`
- [ ] **Listar ações** com responsável + prazo (tabela da ata)

### Até 24h
- [ ] **Enviar follow-up por e-mail** (modelo na agenda)
  - Resumir decisões
  - Agradecer
  - Confirmar próxima reunião
  - Anexar ata + termo assinado (PDF)
- [ ] **Confirmar no WhatsApp** o follow-up
- [ ] **Atualizar repositório**:
  ```bash
  git add docs/atas/AAAA-MM-DD-reuniao-angela-*
  git commit -m "docs: ata da 1ª reunião com Ângela"
  git push
  ```

### Até 48h
- [ ] **Arquivar** no Drive pessoal (backup)
- [ ] **Compartilhar** com orientadora via link (Google Drive)
- [ ] **Atualizar AGENTS.md** se houver mudanças estruturais

### Até 7 dias
- [ ] **Iniciar ações** combinadas (submissão CEP, OSF, etc.)
- [ ] **Reportar progresso** na próxima reunião
- [ ] **Documentar aprendizados** (o que funcionou, o que não)

---

## FASE 4 — MANUTENÇÃO (até próxima reunião)

### Semanal
- [ ] **Commit semanal** no repo (manter momentum)
- [ ] **Issue/PR aberto** se bloqueado
- [ ] **Mensagem curta no WhatsApp** se precisar de algo rápido (sem spam)

### Quinzenal
- [ ] **Relatório de progresso** (1 página) para a Ângela, se ela pedir
- [ ] **Revisão de pendências** da ata

### Mensal (na reunião)
- [ ] **Apresentar** 1 gráfico de progresso (Gantt, burndown, etc.)
- [ ] **Discutir** 1 decisão difícil
- [ ] **Planejar** próximos 30 dias
- [ ] **Atualizar** cronograma-mestre se necessário

---

## 🚨 PLANO B — Se a reunião não for como esperado

### Se ela recusar orientação
- [ ] **Não desesperar** (orientadoras recusam por vários motivos)
- [ ] **Perguntar** o motivo (pode ser timing, escopo, ou pessoa)
- [ ] **Pedir sugestões** de outros orientadores
- [ ] **Manter relação** (pode co-orientar no futuro)
- [ ] **Buscar PPGED/MEC alternativo** se for definitivo

### Se ela pedir para ajustar o escopo
- [ ] **Ouvir** as razões (geralmente são boas)
- [ ] **Negociar** o que é essencial vs. nice-to-have
- [ ] **Focar no P01** (mestrado cabe em 2 anos; P02-P05 viram papers paralelos)
- [ ] **Reduzir** para 3 projetos se necessário (P01 + P03 + P05 = linha coerente)

### Se ela quiser mais tempo para pensar
- [ ] **Marcar** follow-up em 1 semana
- [ ] **Enviar** briefing por e-mail para ela ler com calma
- [ ] **Não pressionar** (relação de longo prazo > decisão apressada)
- [ ] **Preparar** plano B (outro orientador no PPGED)

### Se ela não responder o e-mail em 3 dias úteis
- [ ] **Follow-up breve** (1-2 frases, simpático)
- [ ] **WhatsApp** (se tiver) — pode ser mais rápido
- [ ] **Não ser insistente** (máximo 2 follow-ups; depois respeitar o silêncio)
- [ ] **Buscar** outro contato no PPGED (coordenação)
