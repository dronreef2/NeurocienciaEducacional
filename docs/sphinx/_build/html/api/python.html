Python API Reference

neurociencia_edu

Educational Neuroscience Research Program.

A Python package for analyzing data from research on: - Executive functions (BRIEF-2, Stroop, TMT) - EEG/ERP (MNE-Python) - IRT (Item Response Theory) - SEM (Structural Equation Modeling) - Mixed-effects models - Bayesian analysis - Network analysis

Submodules:

eeg — EEG/ERP preprocessing and analysis stats — Statistical models (SEM, IRT, ANCOVA, mediation) io — Data I/O (BIDS-like) dashboard — Streamlit dashboards
