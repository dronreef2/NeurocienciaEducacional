🧠 Neurociência Educacional

Programa de Pesquisa de 5 anos (2026-2030) investigando como diferentes tecnologias educacionais baseadas em IA impactam o desenvolvimento cognitivo de crianças.

📚 Os 5 Projetos

P01 — Vozes das Crianças

Análise qualitativa com crianças do 2º ano sobre tutores de IA (Khanmigo). Entrevistas + think-aloud + questionários.

Em andamento

P02 — Gamificação & FE

ECR 2×4 fatorial testando gamificação adaptativa sobre funções executivas. N=200.

Em andamento

P03 — EEG / Leitura

Marcadores neurais (N170, P300) de leitura digital vs. papel. Paradigma EEG com N=60.

Setup

P04 — IA Generativa × FE

Estudo transversal correlacional com SEM testando mediação de engajamento. N=300-500.

Em andamento

P05 — Coorte Longitudinal

Acompanhamento de 5 anos (5 ondas anuais) com EEG + neuropsi. N=200 inicial.

Planejado

🔬 Stack Tecnológico

🐍 Python

MNE-Python para EEG/ERP, scikit-learn, scikit-image, statsmodels, pytest, Poetry, Ruff.

📊 R

tidyverse, lavaan, emmeans, OpenMx, tidySEM, testthat, devtools.

📓 Notebooks

4 R Markdown + 3 Jupyter (AT, ANCOVA, LGCM, SEM, EEG/ERP, Bayesian, ML).

📈 Dashboards

Streamlit + Shiny + Bokeh para visualização interativa dos resultados.

🛠️ DevOps

Docker, GitHub Actions (CI/CD), Codecov, Husky, pre-commit, Snakemake, Sphinx.

📦 Reprodutibilidade

renv (R), Poetry (Python), seeds fixos, dados sintéticos, Docker reproduzível.

🚀 Quick Start

Comece a usar o programa em 3 comandos:

📥 Clone o repositório
git clone https://github.com/dronreef2/NeurocienciaEducacional.git
cd NeurocienciaEducacional
🐍 Instale dependências Python
poetry install
poetry run python analise/Python/00_setup.py
📊 Rode uma análise
poetry run neurociencia-eeg-erp --input dados/processed/P03/ --batch
