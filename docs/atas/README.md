# 📁 Atas e Documentos de Reuniões

> **Pasta oficial** para atas de reunião, termos de orientação, e materiais de governança do programa.
> **Convenção de nomenclatura:** `AAAA-MM-DD-[participantes]-[tipo].md`

---

## 📂 Estrutura

```
docs/atas/
├── README.md                                          ← este arquivo
├── 2026-XX-XX-reuniao-angela-briefing.md             ← síntese 2 páginas para levar
├── 2026-XX-XX-reuniao-angela-autorizacao.md          ← termo de orientação (2 vias)
├── 2026-XX-XX-reuniao-angela-agenda.md                ← agenda 15-30 min + roteiro pitch
└── 2026-XX-XX-reuniao-angela-ata.md                   ← ata pré-preenchida para usar no dia
```

---

## 🚀 Como usar (sequência)

### 1. **Antes da reunião** (1 semana antes)
- Ler: `2026-XX-XX-reuniao-angela-briefing.md` (se familiarizar com o conteúdo)
- Imprimir 3 cópias do briefing
- Imprimir 2 vias do `2026-XX-XX-reuniao-angela-autorizacao.md`
- Estudar o roteiro de pitch em `2026-XX-XX-reuniao-angela-agenda.md`
- Consultar: `docs/CHECKLIST-PRE-REUNIAO-ANGELA.md` (visão geral)

### 2. **No dia da reunião**
- Levar os materiais impressos
- Usar `2026-XX-XX-reuniao-angela-ata.md` para anotar decisões em tempo real
- Assinar termo de orientação (se for o caso)

### 3. **Após a reunião** (24-48h)
- Substituir `2026-XX-XX` pela data real: `2026-09-15-reuniao-angela-*.md`
- Preencher a ata com decisões, ações, responsáveis, prazos
- Renomear arquivos mantendo padrão
- Commit + push
